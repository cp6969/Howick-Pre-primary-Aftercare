# Howick Pre-Primary — Aftercare Tracker

Design concept for an aftercare sign-in/sign-out tracker, styled to Howick Pre-Primary
& Baby Centre's actual site branding (colors, Jost/Open Sans typefaces, logo palette).

- **`mockup.html`** — self-contained dashboard mockup (fonts embedded, no external
  requests). Open directly in a browser to view.
- **`Howick-Aftercare-Billing.xlsx`** — companion billing workbook. Four tabs:
  Rates & Settings → Daily Log → Billing Summary → per-child Invoice, all formula-driven
  from logged arrival/collection times.

Not a live system — sample data throughout.
